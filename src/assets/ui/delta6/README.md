# DATA PACKAGE DELTA-6 UI Cards

Editable SVG assets for Mission 01 data package states.

## Files

- `delta6-status-non-secure.svg`
- `delta6-transfer-in-progress.svg`
- `delta6-status-partial.svg`
- `delta6-status-corrupted.svg`
- `delta6-status-secured.svg`
- `delta6-status-lost.svg`

## Specs

- Dimensions: `1920 x 1080`
- Background: transparent
- Format: vector SVG with editable `<text>` and named groups
- Visual language: UESC data recovery interface, CRT green/orange, military industrial telemetry

## Usage

Import the SVGs into Figma or Illustrator for editing, or reference them from the app as regular Vite assets under `src/assets/ui/delta6/`.

The cards intentionally avoid narrative spoilers. They only communicate operational data package status.
